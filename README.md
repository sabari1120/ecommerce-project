# E-Commerce Website

## 📌 About the Project
A full-stack e-commerce web application built using React.js and Spring Boot. 
The application allows users to browse products, manage their cart, authenticate,
and place orders.

## 🚀 Features

### 👤 User
- User registration and login
- User authentication
- Browse products
- View product details
- Add products to cart
- Update cart quantity
- Place orders
- View orders

### 🛍️ Product
- Product management
- Category management
- Product listing
- Product details

### 🛒 Cart & Orders
- Add/remove products from cart
- Update product quantity
- Order management
